# Fahrrad: Simulator und Bike-Check

Zwei interaktive 3D-Seiten zum Fahrradtraining in Klasse 4. Beide sind über Tabs auf einer Seite erreichbar:

- **Für Kinder: Wie funktioniert ein Fahrrad?** ([kinder.html](kinder.html)). Pedale, Kette, Gangschaltung, Bremsen, Licht, Klingel und Rückstrahler zum Ausprobieren, dazu eine Checkliste für ein verkehrssicheres Rad.
- **Für Eltern: Bike-Check** ([eltern.html](eltern.html)). Alle 16 Punkte der Bike-Checkliste am Rad erklärt, jeweils „in Ordnung“ und „mit Mangel“, mit Häkchen zum Abhaken. Die Seite ersetzt die unterschriebene Papier-Checkliste nicht.

Die Startseite [index.html](index.html) wechselt zwischen beiden Seiten; direkte Links gehen mit `#kinder` und `#eltern`.

Jede Seite ist eine einzelne HTML-Datei und läuft auch ohne Internet, zum Beispiel heruntergeladen auf einem Tablet. Am besten im Querformat ansehen.

Erstellt mit [teardown](https://github.com/elvarofficial/teardown) und three.js.
